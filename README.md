# 🎓 Школьный квест

Браузерная игра-викторина: отвечай на вопросы по школьным предметам, чтобы пройти уровень и открыть следующий.

## Как запустить

Никакой установки и зависимостей не нужно — откройте файл `index.html` двойным кликом в любом браузере.

```bash
git clone https://github.com/MihasSskkKAa/sch.git
```

## Правила

- В каждом уровне **8 вопросов** и **3 жизни** (❤️❤️❤️). Вопросы берутся случайно из банка в 16 штук, поэтому два прохождения не совпадают.
- Неверный ответ или истёкшее время отнимают одну жизнь. Кончились жизни — уровень не пройден.
- Прошёл уровень до конца — следующий открывается.
- После каждого ответа показывается правильный вариант и короткое пояснение.
- Прогресс сохраняется в браузере: открытые уровни, очки и звёзды не пропадут после закрытия вкладки.

### Подсказки

На каждый уровень даётся **3 подсказки** (💡). Подсказка не называет ответ прямо, а подталкивает к нему: сужает диапазон, напоминает правило или указывает на связь с чем-то знакомым.

> Сколько гласных букв в русском алфавите?
> 💡 *Ровно столько же, сколько пальцев на двух руках.*

Цена подсказки — половина очков за этот вопрос. На один вопрос можно взять только одну.

### Звук

Верный ответ отмечается коротким восходящим трезвучием. Звуковых файлов в репозитории нет — сигнал синтезируется через Web Audio API прямо в браузере, поэтому игра остаётся полностью автономной.

Кнопка 🔊 в шапке уровня включает и выключает звук, выбор запоминается вместе с прогрессом.

### Очки и звёзды

| Что | Как считается |
| --- | --- |
| Очки за ответ | `100 × номер уровня + 5 × оставшиеся секунды` |
| Очки за ответ с подсказкой | половина от обычных |
| ⭐⭐⭐ | все 8 ответов верны |
| ⭐⭐ | одна ошибка |
| ⭐ | две ошибки |

Сохраняется лучший результат, так что уровень можно перепройти ради трёх звёзд — например, вообще без подсказок.

### Управление с клавиатуры

- `1` – `4` — выбрать вариант ответа
- `H` (или `Р` в русской раскладке) — взять подсказку
- `Enter` или `Пробел` — перейти к следующему вопросу

| 1 | 🎒 Начальная школа | 4–5 класс | 30 сек | 16 |
| 2 | 📘 Средняя школа | 6–7 класс | 28 сек | 16 |

## Структура проекта

```
index.html        — разметка экранов (меню, игра, итоги)
css/style.css     — оформление
js/questions.js   — база вопросов, разбитая по уровням
js/game.js        — игровая логика, таймер, звук, подсчёт очков, сохранение прогресса
```

## Как добавить свои вопросы

Все вопросы лежат в [`js/questions.js`](js/questions.js). Добавьте объект в массив `questions` нужного уровня:

```js
{
  subject: 'Математика',           // название предмета — показывается меткой над вопросом
  text: 'Сколько будет 2 + 2?',    // сам вопрос
  options: ['3', '4', '5', '6'],   // варианты ответа
  correct: 1,                      // индекс верного варианта (нумерация с нуля)
  hint: 'Это число чётное.',       // подсказка: подталкивает, но не называет ответ
  fact: 'Пояснение после ответа.'  // короткий разбор
}
```

Вопросы и варианты ответов перемешиваются при каждом запуске, поэтому порядок в файле не важен. Чем больше вопросов в банке уровня, тем реже они повторяются: в партию попадает `QUESTIONS_PER_ROUND` штук (по умолчанию 8), эта константа задаётся в начале [`js/game.js`](js/game.js) вместе с числом жизней и подсказок.

Чтобы добавить целый уровень, скопируйте блок уровня в массиве `LEVELS` и задайте свои `id`, `title`, `subtitle`, `icon` и `time`.
