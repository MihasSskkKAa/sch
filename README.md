# 🎓 Школьный квест

Браузерная игра-викторина: отвечай на вопросы по школьным предметам, чтобы пройти уровень и открыть следующий.

## Как запустить

Никакой установки и зависимостей не нужно — откройте файл `index.html` двойным кликом в любом браузере.

```bash
git clone https://github.com/MihasSskkKAa/sch.git
```

## Правила

- В каждом уровне **8 вопросов** и **3 жизни** (❤️❤️❤️). Вопросы берутся случайно из банка в 24 штуки, поэтому два прохождения не совпадают.
- Неверный ответ или истёкшее время отнимают одну жизнь. Кончились жизни — уровень не пройден.
- **Провалил уровень — вопросы сменятся полностью.** Набор проваленной попытки откладывается целиком, и повтор собирается из оставшихся вопросов банка. Откладывание накопительное: три провала подряд дадут три полностью разных набора и переберут весь банк из 24 вопросов. На четвёртой попытке начинается новый круг, но вопросы предыдущей партии всё равно придерживаются, чтобы не повториться сразу же. Список хранится в браузере и переживает перезагрузку страницы, а победа очищает его целиком.
- Прошёл уровень до конца — следующий открывается.
- После каждого ответа показывается правильный вариант и короткое пояснение.
- Прогресс сохраняется в браузере: открытые уровни, очки и звёзды не пропадут после закрытия вкладки.

### Подсказки

На каждый уровень даётся **3 подсказки** (💡). Подсказка не называет ответ прямо, а подталкивает к нему: сужает диапазон, напоминает правило или указывает на связь с чем-то знакомым.

> Сколько гласных букв в русском алфавите?
> 💡 *Ровно столько же, сколько пальцев на двух руках.*

Цена подсказки — половина очков за этот вопрос. На один вопрос можно взять только одну.

### Звук

| Событие | Как звучит |
| --- | --- |
| Верный ответ | короткое восходящее трезвучие, светлый тембр |
| Неверный ответ или истёкшее время | низкий сигнал, падающий вниз, глуше и мягче |

Звуковых файлов в репозитории нет — сигнал синтезируется через Web Audio API прямо в браузере, поэтому игра остаётся полностью автономной.

Кнопка 🔊 в шапке уровня включает и выключает звук, выбор запоминается вместе с прогрессом.

### Секундомер

Общее время прохождения уровня идёт в шапке рядом с номером вопроса (⏱). В отличие от таймера на вопрос он не останавливается на разборе ответа — считается всё время от старта уровня до итогов. Результат показывается на экране итогов и попадает в таблицу рекордов.

### Таблица рекордов

Таблица устроена как сводка: строка — игрок, столбец — уровень. В ячейке лучший результат этого игрока на этом уровне, цвет показывает звёзды, а при наведении видно время и дату. Последний столбец — сумма лучших результатов по всем уровням, по ней таблица и отсортирована. Непройденный уровень отмечен прочерком, проваленные попытки не записываются.

Открывается кнопкой 🏆 из меню или с экрана итогов. Имя игрока обязательно: пока поле в меню пустое, уровни не запускаются — иначе рекорд некому подписать. Имя запоминается и правится как в меню, так и в самой таблице. Кнопка «Очистить таблицу» стирает только рекорды — прогресс по уровням остаётся.

У таблицы две вкладки: **«Общий рейтинг»** — общий для всех игроков (требует подключения Supabase, см. ниже) и **«Мои результаты»** — локальная, работает всегда и без интернета.

### Очки и звёзды

| Что | Как считается |
| --- | --- |
| Очки за ответ | `100 × номер уровня + 5 × оставшиеся секунды` |
| Очки за ответ с подсказкой | половина от обычных |
| ⭐⭐⭐ | все 8 ответов верны |
| ⭐⭐ | одна ошибка |
| ⭐ | две ошибки |

Сохраняется лучший результат, так что уровень можно перепройти ради трёх звёзд — например, вообще без подсказок.

### Управление с клавиатуры

- `1` – `4` — выбрать вариант ответа
- `H` (или `Р` в русской раскладке) — взять подсказку
- `Enter` или `Пробел` — перейти к следующему вопросу

## Общий рейтинг (Supabase)

Игра — набор статических файлов, поэтому общий рейтинг хранится во внешней базе. Пока `js/config.js` не заполнен, вкладка «Общий рейтинг» показывает подсказку по настройке, а игра работает как обычно.

### 1. Создайте проект

Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте бесплатный проект.

### 2. Создайте таблицу

В разделе **SQL Editor** выполните запрос:

```sql
create table public.records (
  id          bigint generated always as identity primary key,
  player      text        not null check (char_length(player) between 1 and 16),
  level       int         not null check (level between 1 and 99),
  level_title text        not null check (char_length(level_title) <= 64),
  score       int         not null check (score between 0 and 100000),
  stars       int         not null check (stars between 0 and 3),
  duration_ms int         not null check (duration_ms between 0 and 86400000),
  created_at  timestamptz not null default now()
);

alter table public.records enable row level security;

create policy "читать может каждый"
  on public.records for select using (true);

create policy "добавлять может каждый"
  on public.records for insert with check (true);
```

Ограничения `check` — это заслон от мусора: слишком длинного имени, отрицательных очков, неправдоподобного времени. Политики RLS разрешают только чтение и добавление: удалять и править чужие записи через публичный ключ нельзя.

### 3. Впишите ключи

В **Project Settings → Data API** возьмите `Project URL` и публичный ключ `anon` и вставьте их в [`js/config.js`](js/config.js):

```js
const SUPABASE = {
  url: 'https://ваш-проект.supabase.co',
  anonKey: 'eyJ...'
};
```

Ключ `anon` предназначен для публикации в коде клиента — доступ ограничивают политики RLS, а не секретность ключа.

### Что важно понимать

- **Накрутить результат может любой.** Очки считаются в браузере, поэтому подделать запрос к базе несложно. Честный рейтинг потребовал бы проверки ответов на сервере — это отдельная задача.
- **Игра не ломается без сети.** Если база недоступна, отправка результата тихо пропускается, а вкладка показывает понятную ошибку — локальная таблица продолжает работать.


## Как добавить свои вопросы

Все вопросы лежат в [`js/questions.js`](js/questions.js). Добавьте объект в массив `questions` нужного уровня:

```js
{
  subject: 'Математика',           // название предмета — показывается меткой над вопросом
  text: 'Сколько будет 2 + 2?',    // сам вопрос
  options: ['3', '4', '5', '6'],   // варианты ответа
  correct: 1,                      // индекс верного варианта (нумерация с нуля)
  hint: 'Это число чётное.',       // подсказка: подталкивает, но не называет ответ
  fact: 'Пояснение после ответа.'  // короткий разбор
}
```

Вопросы и варианты ответов перемешиваются при каждом запуске, поэтому порядок в файле не важен. Чем больше вопросов в банке уровня, тем реже они повторяются: в партию попадает `QUESTIONS_PER_ROUND` штук (по умолчанию 8), эта константа задаётся в начале [`js/game.js`](js/game.js) вместе с числом жизней и подсказок.

Чтобы добавить целый уровень, скопируйте блок уровня в массиве `LEVELS` и задайте свои `id`, `title`, `subtitle`, `icon` и `time`.
